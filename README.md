# Generative-AI
Generative AI Semester V

 Course Objective:

To provide hands-on experience in developing deep learning models for intelligent applications.
To enable students to implement deep learning and generative AI techniques using modern frameworks.
To impart practical skills in building and evaluating AI-driven applications.
To familiarize students with developing real-world applications using pretrained models and Generative AI technologies.
 

Course Outcome:

 

Develop CNN and Transfer Learning models for image classification tasks using modern deep learning frameworks. [L3]
Build sequence learning models using Embedding Layers and LSTM networks for text classification problems.[L3]
Implement Autoencoder and Variational Autoencoder models for image reconstruction and analyze generated outputs.[L4]
Develop image generation applications using pretrained Diffusion Models and Generative Adversarial Networks.[L4]
Design Retrieval-Augmented Generation (RAG) applications using pretrained LLMs, vector databases, and prompt engineering techniques. [L5]
